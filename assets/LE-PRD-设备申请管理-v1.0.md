## 4. 流程设计

### 4.1 设备修改申请（变更申请）

一张单覆盖五类变更，按类型分流执行与验收方式：

| 类型 | 执行方式 | 验收方式 | 台账回写 |
|------|---------|---------|---------|
| 故障维修 | 内部维修 / 外委维修 | 试运行确认 | 状态恢复"运行中"，维修履历 +费用 |
| 保养（含计量校准） | 按计划或临时发起 | 保养记录 / 校准证书上传 | 保养履历、下次保养/校准日期 |
| 改造升级 | 内部改造 / 供应商改造 | 试运行 + 参数确认 | 更新设备参数档案 |
| 移装 / 调拨 | 拆装、运输 | 上电试运行 | **更新位置与权属 BU** |
| 报废 | 停用封存 | 资产处置确认 | 状态改"报废"，移出运行统计 |

主流程：

```
申请人提交 ──→ 设备管理员初审 ──→ 工程师评审 ──→ 分级审批 ──→ 执行 ──→ 验收 ──→ 关闭回写台账
   │              │驳回             │驳回          │驳回                      │不合格
   └─ 撤回 ←─────┴────────────────┴─────────────┘                退回执行重新处理
```

| 步骤 | 关键动作 | 系统行为 |
|------|---------|---------|
| 1 提交 | 从台账选设备 → 选变更类型 → 问题描述 → **照片必传** → 紧急程度 → 期望完成时间；移装需填目标 BU/位置；报废需填原因 | 生成单号 CHG-YYYYMMDD-XXX；设备状态预锁定 |
| 2 初审 | 设备管理员核实真实性、紧急度 | 驳回退回申请人（附意见） |
| 3 评审 | 工程师填方案、预估费用工时、**停机影响范围（影响哪些产线/BU）** | 费用/资产价值自动匹配审批级 |
| 4 分级审批 | 见 4.3 规则 | 通过后状态流转；维修/保养类设备锁定对应状态 |
| 5 执行 | 派工打卡、进度更新、前后对比照片 | 申请人全程可见进度 |
| 6 验收 | 试运行 + 双签确认；校准类上传证书 | 合格→关闭；不合格→退回执行 |
| 7 回写 | 自动 | 履历入设备详情页，费用归集，统计卡片实时刷新（现有 BU 卡片的"维修中"计数自动联动） |

### 4.2 设备购买申请

```
申请人提交 ──→ BU负责人审批 ──→ 工程师选型评审 ──→ 分级审批 ──→ 采购比价 ──→ 到货安装验收 ──→ 入台账关闭
```

| 步骤 | 关键动作 | 系统行为 |
|------|---------|---------|
| 1 提交 | 类型（全新购置 / 更新替换→**关联旧设备单据**）→ 用途与安装位置（选 BU）→ 预算 → 期望到货 → 图纸/技术参数附件 | 生成单号 PUR-YYYYMMDD-XXX |
| 2 BU 负责人审批 | 审必要性、预算归属 | — |
| 3 选型评审 | 设备工程师：参数匹配、产能匹配、能耗与场地、**医疗器械行业资质要求（如适用）** | 输出选型意见 |
| 4 分级审批 | 见 4.3 | 通过→流转采购 |
| 5 采购比价 | **≥3 家报价 + 供应商资质核验**（营业执照、行业许可/授权） | 比价表强制留档；选中价与最低价差 >10% 需填说明 |
| 6 安装验收 | 开箱检验 → 安装调试 → 试运行（≥N 小时）→ 双签 | 不合格→退供应商；合格→下一步 |
| 7 入台账 | 系统自动建档：资产编号、参数、图册、**归属 BU**、位置 | 计入该 BU"设备总数"卡片 |

### 4.3 分级审批规则（阈值可在系统管理中配置）

| 单据 | 条件 | 审批链 |
|------|------|--------|
| 修改申请 | 预估费用 < 5,000 元 | 设备管理员 → 设备主管 |
| 修改申请 | 5,000 ≤ 费用 < 30,000 元 | 设备管理员 → 工程师评审 → 设备经理 |
| 修改申请 | 费用 ≥ 30,000 元，或改造/移装/报废 | 设备管理员 → 工程师评审 → 设备经理 → **BU 负责人**；报废与 ≥100,000 元再加签**总经理** |
| 购买申请 | 预算 < 50,000 元 | BU 负责人 → 选型评审 → 采购主管 |
| 购买申请 | 50,000 ≤ 预算 < 200,000 元 | BU 负责人 → 选型评审 → 采购主管 → **设备经理/副总** |
| 购买申请 | 预算 ≥ 200,000 元 | 上述链 → **总经理** |
| 任意 | 停产紧急 | 全链 ≤2h 处理，超时电话/短信升级催办 |

> 医疗器械行业的合规提示：涉及计量器具的保养/校准类申请，验收环节必须上传校准证书；报废涉及受监管设备的，建议在"报废"类型备注法规处置要求（由质量部确认，V1.0 以备注字段承载，不建独立流程）。

### 4.4 审批流引擎（状态机）

```
草稿 → 已提交 → 审批中 ⇄（驳回回退指定节点）→ 已批准 → 执行中 → 待验收 → 已关闭
                  ↓                                          ↑
               已撤回（申请人）                验收不合格 ────┘
```

1. **配置化流程定义**：`申请类型 + 条件（金额/资产价值/紧急度）→ 节点序列`，存 JSON，系统管理员可视化调整，不改代码；
2. **审批操作**：通过 / 驳回（回指定节点）/ 转办 / 加签 / 撤回，意见必填；
3. **超时治理**：24h 提醒 → 48h 升级上级 → 紧急单 2h 一催；
4. **全留痕**：动作、意见、时间、附件访问记录不可篡改。
